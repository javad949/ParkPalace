# گزارش بازیابی‌شده از CSVهای موجود

این گزارش محلی پس از شکست مرحله تولید Markdown ساخته شد. هیچ اتصال یا استعلام جدید انجام نشده است.

- سرور ثبت‌شده در خروجی کاربر: SEPIDAR\SEPIDAR؛ دیتابیس: Sepidar01.
- Snapshot خاموش و RCSI برابر False است.
- پنج ردیف سابقه بکاپ کامل دریافت شد؛ وجود فایل و قابلیت بازیابی بررسی نشده است.
- اطلاعات دو فایل tempdb دریافت شد؛ این اطلاعات جایگزین فضای آزاد دیسک نیست.
- بررسی فضای واقعی دیسک و تراکنش‌های فعال هر دو با خطای نبود VIEW SERVER STATE ناموفق شدند. فایل خالی در این دو بخش به معنی صفر یا نبود تراکنش نیست.
- تاریخ‌ها و اعداد با فرهنگ محلی صادر شده‌اند (از جمله ممیز / و سال ۱۴۰۵ در رشته دارای Z). دو تاریخ سابقه بکاپ نیز سال ۱۴۱۴ نشان می‌دهند. بدون بررسی قالب استاندارد و ساعت سرور، درباره تازگی بکاپ یا اختلاف ساعت نتیجه قطعی نگیرید.
- نتیجه: بررسی جزئی؛ برای تأیید تغییر Snapshot کافی نیست. هیچ تنظیم یا دسترسی تغییر نکرده است.
